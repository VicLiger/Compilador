# Compilador em Python

Projeto desenvolvido para a disciplina de Compiladores.

## Requisitos

- Python 3.14

## Como executar

Escreva o código da linguagem no arquivo:

```txt
code.txt
```

Execute:

```bash
python main.py
```

## Comandos disponíveis

### Variáveis

```txt
x = 10
nome = "Victor"
ativo = true
```

### Operações

```txt
x + y
x - y
x * y
x / y
```

### Comparações

```txt
x > y
x < y
x == y
x != y
```

### If / Else

```txt
if x > 10 then print "Maior" else print "Menor"
```

### While

```txt
while x < 10 then x = x + 1
```

### Print

```txt
print x
```

### Read

```txt
read nome
```

### Funções

```txt
func dobro(x) return x * 2

resultado = dobro(10)

print resultado
```
